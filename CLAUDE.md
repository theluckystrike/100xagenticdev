# 100x Agentic Engineer Pipeline

## Operating Principles
- Full autonomy: no manual steps
- NASA Power of 10 code stability rules
- Compound returns over linear effort
- Surgical precision: triple-check before shipping
- Chunked execution: one chunk at a time, self-review each

## Project Structure
- `research/` — Karpathy study, LLM infrastructure research
- `pipeline/` — Architecture docs, setup guides
- `config/` — Settings, ESLint, hooks
- `scripts/` — Automation scripts, pipeline runners
- `evals/` — Eval cases, test suites
- `memory/` — LLM Wiki, knowledge graph
- `docs/` — Reports and documentation

## Code Rules
- Functions under 60 lines
- All loops have fixed upper bounds
- No unbounded memory allocation
- No global mutable state
- Check every return value
- No dangerous mutations
- Zero warnings policy
